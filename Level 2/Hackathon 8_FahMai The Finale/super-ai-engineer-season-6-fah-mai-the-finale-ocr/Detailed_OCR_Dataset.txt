Description
This competition focuses on optical character recognition (OCR) and document understanding across a diverse set of business documents. Participants are given rendered images/PDFs and must extract text for evaluation.

Task
Given a document image or PDF from the renders/ folder, produce OCR text output for the corresponding artifact. Each render has a matching provenance JSON in per_artifact/ that provides metadata, template type, and the path to the rendered file.

Your job is to use the OCR model to predict the JSON like in the per_artifact folder

Evaluation

Submissions are evaluated using the Weighted Character Error Rate (CER), a character-level edit distance metric adapted for structured field extraction.

Bold/italic markers (*) are stripped
